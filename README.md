# Amazon Sales Analysis Dashboard | Power BI

## Project Overview

This project presents an interactive Amazon Sales Analysis dashboard built using Microsoft Power BI.

The dashboard helps explore sales performance, monitor key business KPIs, analyze sales trends, and identify top-performing products.

## Objectives

* Monitor key sales performance indicators.
* Analyze Year-to-Date (YTD) and Quarter-to-Date (QTD) sales.
* Explore monthly and weekly sales trends.
* Identify top-performing products.
* Understand product sales and review-related metrics.
* Present business data through interactive visualizations.

## Tools Used

* Microsoft Power BI
* Power Query and DAX, if used in the project

## Dashboard Features

### Key Performance Indicators (KPIs)

* YTD Sales
* QTD Sales
* Products Sold
* Reviews

### Visual Analysis

* Monthly sales trends
* Weekly sales trends
* Top products analysis
* Category and quarter filters

`Amazon-Sales-Analysis.pbix`

Download the PBIX file from this repository and open it using Power BI Desktop.

## How to Use

1. Download the `.pbix` file.
2. Install Microsoft Power BI Desktop.
3. Open the downloaded file in Power BI Desktop.
4. If prompted, configure the required data source or file path.
5. Refresh the data if the original data source is available and refresh is required.
